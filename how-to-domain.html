How-To: Custom Domain

Turn yourname.github.io into yourname.com. Takes about 10 minutes to set up, then a few hours to go live.

Do you need a custom domain?

No. Your Autonom site works perfectly at yourname.github.io — that's a real URL you can share, put on a business card, and link from social media. It's free and it never expires.

A custom domain like yourname.com is optional. It looks more professional and is easier to remember. Domains typically cost $10–20 per year from any registrar. That cost is between you and whoever you buy it from — Autonom has nothing to do with it.

This guide uses Namecheap as the example registrar — they're straightforward and commonly used. The steps are nearly identical on GoDaddy, Google Domains, Squarespace Domains, Cloudflare Registrar, or anywhere else. The DNS record values are always the same.

Step 1 — Buy a domain

Go to a domain registrar and search for the name you want. Common choices:

  • Namecheap — straightforward, no upsell pressure
  • Squarespace Domains — clean interface, slightly pricier
  • Cloudflare Registrar — at-cost pricing, best value, slightly more technical
  • GoDaddy — widely known, watch for renewal price jumps

Search for yourname.com. If it's taken, try .net, .co, .me, or add a word like yourname.art or yourname.dev. Buy it. You'll get an account with the registrar — keep those login details somewhere safe.

Step 2 — Tell GitHub about your domain

Go to your GitHub repository. The URL looks like: github.com/yourusername/yourusername.github.io

  1. Click the Settings tab at the top of your repository.
  2. In the left sidebar, click Pages.
  3. Under Custom domain, type your domain — for example yourname.com.
  4. Click Save.

GitHub will show a warning that the DNS isn't configured yet. That's fine — you're about to do that. GitHub also automatically creates a file called CNAME in your repository. Don't delete it.

Step 3 — Add DNS records at your registrar

DNS records are how the internet knows that yourname.com should point to GitHub's servers. Log in to your registrar and find the DNS settings or Advanced DNS section for your domain.

You need to add these records:

Type Host / Name Value TTL
A@185.199.108.153Automatic
A@185.199.109.153Automatic
A@185.199.110.153Automatic
A@185.199.111.153Automatic
CNAMEwwwyourusername.github.ioAutomatic

The four A records point your root domain (yourname.com) to GitHub's servers. The CNAME record makes www.yourname.com work too. Replace yourusername in the CNAME value with your actual GitHub username.

On Namecheap: go to Domain List → Manage → Advanced DNS. Delete any existing A records pointing somewhere else, then add the five records above.

On Squarespace Domains: go to Domains → your domain → DNS Settings. Same idea — add the records, remove any conflicting ones.

Step 4 — Wait, then verify

DNS changes take time to spread across the internet. Usually it's 15–60 minutes. Sometimes it takes up to 24 hours. This is normal — you can't speed it up.

Once it's done, go back to GitHub → your repo → Settings → Pages. You should see a green checkmark and a message that says your site is published at your custom domain. GitHub also automatically enables HTTPS (the padlock) — this can take a few extra minutes after the DNS resolves.

If it's been more than 24 hours and it's still not working: double-check that the CNAME record value matches your exact GitHub username, and that you saved the domain in GitHub Pages settings. Those are the two most common mistakes.
