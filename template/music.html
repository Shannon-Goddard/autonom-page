GitHub stores up to ~1GB total across your whole site. For most people that’s plenty. If you have a large music collection, you can connect a free Cloudflare R2 bucket — 10GB free, no fees to stream your music, takes about 2 minutes to set up.

⚠️ Your R2 credentials will be stored on this device only. Keep them safe — if you clear your browser storage you’ll need to re-enter them.

Connect Cloudflare R2

  1. Create a free account at cloudflare.com, then go to R2 Object Storage and create a bucket.
  2. In your bucket settings, enable Public Access and copy the public bucket URL.
  3. Go to Manage R2 API Tokens, create a token with Object Read & Write permission scoped to your bucket. Copy the Account ID, Access Key ID, and Secret Access Key.
