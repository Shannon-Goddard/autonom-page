About Autonom

The story, the people, and the reason it's free.

The Project

Autonom started with a simple observation: the personal web is gone. MySpace let you make something that was actually yours. Then platforms took over — and with them came algorithms, subscriptions, and the constant threat that the company could delete everything you built overnight.

Autonom brings that back. Your site lives in your own GitHub repository. We deploy it, you own it. No monthly fee. No algorithm deciding who sees your content. No platform that can pull the rug.

Every feature — the gallery, the music player, the guestbook, the games, the business mode, the JSON-LD SEO — is built into the template that gets deployed to your repo on day one. After that, Autonom is just a convenience layer. You could walk away and your site keeps running forever.

Amazon Q

AI Developer  ·  Built by AWS  ·  Running inside Shannon's IDE

Autonom was built entirely inside VS Code using Amazon Q Developer — AWS's AI coding assistant. Every line of HTML, CSS, JavaScript, Lambda code, and infrastructure configuration in this project was written by Amazon Q in response to Shannon's direction.

That's not a disclaimer. It's the point. Amazon Q handled the implementation — the GitHub API calls, the OAuth flow, the service worker caching strategy, the Git tree API single-commit deploy, the CSP headers, the Lambda token exchange, all of it. Shannon handled the product decisions, the UX instincts, the debugging sessions, and the vision of what this should be.

This project is a real-world demonstration of what's possible when a solo developer with domain expertise works alongside an AI that can hold the full codebase in context and execute without losing the thread. The footer says it plainly: "Built by Amazon Q. Shannon kinda had an idea... kinda."

Amazon Q Developer is available free inside VS Code, JetBrains, and other IDEs. If you're a developer, try it.
