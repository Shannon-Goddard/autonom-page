Terms of Service

Last updated: October 2026

Autonom is a free tool that creates a GitHub Pages website in your GitHub account. By using it, you agree to these terms.

What Autonom does

Autonom uses GitHub's API to create a repository in your account and deploy a website template to it. After that, your site runs on GitHub Pages — a free service operated by GitHub (Microsoft). Autonom is a setup tool. Once your site is deployed, it runs independently of us.

What you're responsible for

You own your GitHub account and everything in your repository. You're responsible for the content you publish on your site. Don't use Autonom to publish anything illegal, harassing, or that violates GitHub's own Acceptable Use Policies. If GitHub removes your repository for a policy violation, that's between you and GitHub — not us.

GitHub dependency

Autonom depends on GitHub Pages being free and available. GitHub has offered free Pages hosting since 2008 and there's no indication that's changing, but we can't guarantee it forever. If GitHub changes their policies, your repository and all your content will still be yours — you can move it anywhere that hosts static sites (Netlify, Vercel, Cloudflare Pages, your own server).

Autonom is provided as-is. We make no guarantees about uptime, data integrity, or fitness for any particular purpose. The onboarding service (the Lambda function that handles GitHub OAuth) is a best-effort free service. If it goes down, your existing site is unaffected — it runs on GitHub's infrastructure, not ours.

Privacy Policy

Last updated: October 2026

Short version: we don't collect your data, we don't store it, and we don't sell it. Here's the longer version.

What happens during onboarding

When you connect your GitHub account, you're redirected to GitHub's OAuth flow. GitHub sends us a temporary authorization code. Our Lambda function exchanges that code for a GitHub access token on your behalf and returns it to your browser. We do not store that token. It lives in your browser session only, used to make API calls to GitHub, and is gone when you close the tab.

The Lambda function logs are retained by AWS CloudWatch for 14 days by default. Those logs may contain your GitHub username and installation ID (a public identifier), but never your access token — the token is passed directly to your browser, not logged.

What we don't do

We don't run analytics on this site. No Google Analytics, no tracking pixels, no cookies, no fingerprinting. There's no account system, no email list, no database of users. We genuinely don't know who you are after you leave this page.

Your deployed site

Your site lives in your GitHub repository. Any data your visitors generate (guestbook entries, etc.) is stored as JSON files in that repository via GitHub's API, using your own access token. We never see or touch that data after onboarding is complete.

GitHub's privacy policy

Because Autonom uses GitHub Pages and GitHub's API, GitHub's own privacy practices apply to your repository and site traffic. See GitHub's Privacy Statement.

Third-party services on your deployed site

The template we deploy includes optional integrations (Google Search Console, Google Analytics). These are opt-in — you configure them yourself in your site's settings panel. If you enable them, Google's privacy policies apply to your site's visitors. That's your call to make, not ours.
