How it works

You don't need to know anything about code, servers, or web hosting. If you can fill out a form, you can do this.

  1. 1
    Make a free GitHub account

    GitHub is where your website will live. Think of it like a Google Drive for your site — except it also hosts it for free. Takes about two minutes.

    Create your GitHub account →
  2. 2
    Click "Get Started" and fill in your name

    Connect your GitHub account, type your name and a short bio, add a photo if you want. That's the whole form. We build and deploy your site automatically — no settings to configure, no files to upload.

    Go to the form →
  3. 3
    Your site is live — share it, edit it, own it

    You get a real URL: yourname.github.io. Share it anywhere. Log back in any time to update your bio, add photos, change your theme, or connect a custom domain. Everything saves directly to your GitHub — no Autonom account needed after setup.

You've filled out harder forms than this. The whole thing takes under five minutes.

Questions

What is GitHub?

GitHub is a free service where developers store code. Autonom uses it as your personal file storage and web host — you don't need to know how to code to use it.

Why do I need a GitHub account?

GitHub Pages is the free hosting that powers your site. Your photos, music, and content all live in a repository on your GitHub account — not on our servers. That means we can never delete your content, and you own it completely.

How do I create a GitHub account?

Go to github.com/signup — it takes about two minutes. You just need an email address.

Is this really free?

Yes. GitHub Pages is free for public repositories. Autonom itself is free. The only optional cost is a custom domain (like yourname.com) from any registrar — that's between you and them, nothing to do with us.

What does Autonom store about me?

Only your GitHub username and your public site URL — so other users can find you in the directory. That's it. All your content lives in your own GitHub repository. We have no access to it.

Can I take my site and leave?

Yes, any time. Your site is a standard GitHub Pages repository. You can export a full zip backup from your page's admin panel, or just keep using GitHub directly. Autonom is a convenience layer, not a lock-in.
